Planning & Design

How the website was planned using the five layers of UX design: Strategy, Scope, Structure, Skeleton and Surface.

The five layers

LayerDecisions for this project
1. StrategyInformational website. Purpose: help ICT and Cybersecurity students at Bahrain Polytechnic prepare for internships and graduate jobs. Problem: students struggle to find specific, practical guidance and to prepare strong applications.
2. ScopeSeven pages, navigation menu, registration form with JavaScript validation, career guidance content, responsive layouts, planning documentation and AI documentation. HTML5, CSS3, Bootstrap 5, JavaScript ES6, no backend.
3. StructureOne home page plus three subtopics (career paths, CV advice, interview preparation), a planning page, an AI report and an overview. Every page shares one navigation bar.
4. SkeletonHome: header, hero, introduction, topic cards, call to action, registration form, footer. Subpages: title, introduction, main content, tips, related links, footer. Bootstrap grid: 3 columns on desktop, 2 on tablet, 1 on mobile.
5. SurfacePolytechnic Navy & Cyan palette, liquid-glass floating capsule navigation bar, Outfit for titles, system sans-serif for body text, icons, consistent cards with subtle shadows.

Planning documentation

What we decided before building, and how the design changed while we worked.

Audience and need

Who: ICT and Cybersecurity students at Bahrain Polytechnic preparing for internships and first jobs.

Need: practical, specific guidance on roles, CVs and interviews instead of generic advice.

Success: a student can find the right topic from the home page in one click and register their interest.

Content plan

  • Career Paths: entry-level roles and the skills each one needs.
  • CV Advice: building a CV that gets read, with examples.
  • Interviews: technical and behavioural preparation, with a STAR practice tool.
  • Documentation pages: planning and design, AI report, overview.

How the design evolved

  1. Basic seven-page structure and navigation.
  2. Nordic Ocean palette with the Outfit heading font.
  3. Bento card layout and an auto-playing carousel on the home page.
  4. Final Polytechnic Navy & Cyan theme with a floating glass navigation bar.
  5. Interactive CV and interview tools, then the remaining pages.

Inspired by the Bahrain Polytechnic crest, deep navy (#0A192F, #102A43) paired with ocean blue (#0284C7), bright cyan (#7DD3FC) and ice alabaster (#F4F8FB) gives the hub a crisp academic technology identity.

Design reasoning: Outfit is a geometric display font that gives headings a modern tech identity, while body text uses a plain sans-serif so longer passages stay effortless to read.

Design decisions

AreaDecisionReason
NavigationOne floating glass navigation bar, identical on all seven pages, collapsing to a menu button on smaller screens.Users always know where they are and can reach any page in one click.
ColourPolytechnic Navy & Cyan palette: ice alabaster background, deep navy for structure and text, ocean blue and cyan for actions.A crisp, academic technology look inspired by Bahrain Polytechnic, with high-contrast buttons.
TypographyOutfit for headings, system sans-serif for body text.Distinct headings, and body text that loads fast and stays easy to read.
LayoutBootstrap 12-column grid with rounded cards.Content groups are easy to scan and the layout adapts without extra code.
Registration formMessages appear beside each field, the mobile field accepts digits only, and a clear success or error message follows submission.Users see what to fix immediately instead of after the form is rejected.
AccessibilitySkip link, visible focus outline, image alt text, labelled navigation and form fields.The site should work for keyboard and screen reader users as well as mouse users.
TechnologyHTML5, CSS3 (variables in one stylesheet), Bootstrap 5.3, JavaScript ES6, no backend.Matches the brief, and one stylesheet made theme changes quick.
