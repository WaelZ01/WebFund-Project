Planning & Design

How the website was planned using the five layers of UX design: Strategy, Scope, Structure, Skeleton and Surface.

The five layers

LayerDecisions for this project
1. StrategyInformational website. Purpose: help ICT and Cybersecurity students at Bahrain Polytechnic prepare for internships and graduate jobs. Problem: students struggle to find specific, practical guidance and to prepare strong applications.
2. ScopeSeven pages, navigation menu, registration form with JavaScript validation, career guidance content, responsive layouts, planning documentation and AI documentation. HTML5, CSS3, Bootstrap 5, JavaScript ES6, no backend.
3. StructureOne home page plus three subtopics (career paths, CV advice, interview preparation), a planning page, an AI report and an overview. Every page shares one navigation bar.
4. SkeletonHome: header, hero, introduction, topic cards, call to action, registration form, footer. Subpages: title, introduction, main content, tips, related links, footer. Bootstrap grid: 3 columns on desktop, 2 on tablet, 1 on mobile.
5. SurfaceVapour Chrome palette, Purple Purse for titles, system sans-serif for body text, icons, consistent cards with subtle shadows.
