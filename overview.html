1. Project Overview

Career Prep Hub Summary

Website Title: Career Prep Hub

Website Category: Informational & Educational Website

Target Audience: Undergraduate ICT and Cybersecurity students at Bahrain Polytechnic preparing for industry internships and entry-level graduate roles.

Designed for practical use beyond the classroom to bridge coursework and employment.

Problem Statement

ICT and Cybersecurity students complete rigorous technical labs in networking, programming and security, yet many struggle when applying for internships or graduate jobs. Online career advice is often generic, written for experienced engineers abroad, and fails to explain how students in Bahrain can turn university modules and lab coursework into compelling CVs and confident interview answers.

Project Objectives & Real-World Relevance

  • Centralise tailored career guidance: Explain six core ICT and cybersecurity career paths (SOC Analyst, Network/Cloud Engineer, Software Developer, Security Tester, Systems Support and GRC Analyst) and map them to Polytechnic lab skills.
  • Provide interactive self-assessment tools: Help students actively evaluate their readiness through a career-path matcher, an 8-point CV checklist, a live STAR answer builder and a practice interview question generator.
  • Demonstrate front-end engineering best practices: Implement a responsive 7-page architecture using HTML5, CSS3 custom variables, Bootstrap 5.3 and ES6 client-side form validation.
  • Limitations & future improvements: The site currently operates as a client-side static application without a database. Future iterations will connect the registration form to a backend student mailing list and add downloadable CV templates.

Technical Implementation

  • HTML5 Semantic Architecture: Built 7 valid HTML5 pages using <header>, <nav>, <main>, <section>, <article>, <figure> and <footer> landmarks with ARIA labels and a skip-to-content link.
  • CSS3 & Liquid-Glass UI System: Implemented a floating liquid-glass capsule navbar (backdrop-filter: blur(22px) saturate(180%)), custom Bento cards with top gradient borders and responsive media queries.
  • Bootstrap 5.3 Integration: Utilised the 12-column responsive grid (row, col-md-6, col-lg-4), collapsible mobile navbar, auto-playing Carousel, Accordion, Progress Bar and responsive tables.
  • JavaScript ES6 & Browser Storage: Implemented regex and length validators on the registration form and used localStorage and sessionStorage (with JSON.stringify and JSON.parse) to store, display, reload and clear submitted student data across forms.

Challenges We Faced & Solutions

  • 1. Mobile Input Validation Order Bug: Initially, the validation listener ran before non-digit characters were stripped, leaving valid 8-digit numbers marked invalid. Solution: Reordered the listeners in js/main.js and removed hard truncation so 7-digit and 9-digit test cases trigger proper error messages.
  • 2. Button Colour Contrast (WCAG AA): Our contrast audit revealed white text on an earlier orange button reached only 3.08:1 (below the 4.5:1 AA minimum). Solution: Switched to the Polytechnic Navy & Cyan palette where primary buttons reach 4.60:1 (AA) and headings exceed 13:1 (AAA).
  • 3. Generic AI Content Drafts: Early AI drafts produced generic US career advice and unverified salary figures. Solution: Fact-checked every section and rewrote examples around Bahrain Polytechnic modules (Packet Tracer, Wireshark, web projects).
  • 4. Team Git Consistency & Storage Persistence: Coordinating 4 members editing 7 pages required shared conventions. Solution: Used one shared stylesheet and added full localStorage / sessionStorage display tables for form submissions.

4. User Journey Map (Entry to Exit)

How a final-year Bahrain Polytechnic ICT or Cybersecurity student interacts with Career Prep Hub:

Stage Page Visited User Action System Response & Value
1. Entry & Discovery home.html Lands on the hero banner, scans the 4-tile project overview and watches the educational carousel. Understands the site is tailored for Bahrain Polytechnic students and clicks Explore career paths.
2. Role Exploration subtopic1.html Reads the 6 role cards, compares skills in the table and clicks an interest in the interactive matcher. Matcher highlights a recommended track (e.g., SOC Analyst) and lists which lab skills to put on a CV.
3. CV Preparation subtopic2.html Reviews the project bullet formula, compares weak vs. strong bullets and ticks items in the CV checklist. Live progress bar updates from 0% to 100% and confirms when all 8 CV readiness criteria are met.
4. Interview Practice subtopic3.html Expands technical questions in the accordion, drafts a STAR story and tests themselves with the question generator. Combines the STAR inputs with a live word counter, copies the answer and reveals interview tips on demand.
5. Registration & Exit home.html#register Returns to the Home page registration form, enters name, 8-digit mobile and email, and clicks Register now. JavaScript validates each field in real time, displays a personalised confirmation banner and resets the form cleanly.

8. UI Style Guide & 9. Responsive Design Plan

Colour Palette (Polytechnic Navy & Cyan System)

Primary Color: #0A192F / #102A43
Deep Polytechnic Navy (Headers, liquid-glass navbar, body text, footer)

Secondary Color: #F4F8FB / #E2ECF5
Ice Alabaster & Cool Silver (Page background & alternating sections)

Accent Color: #0284C7
Ocean Blue (Primary CTA buttons, checkboxes, focus rings)

Highlight Accent: #7DD3FC
Bright Polytechnic Cyan (Active nav capsule pill, icon highlights, badges)

Gradient Accent: #1D4ED8
Royal Cobalt Blue (Hero & card accent gradients)

Typography

  • Heading Fonts: Outfit (Google Fonts, weights 600 & 700) — h1: clamp(2.15rem, 5vw, 3.25rem), h2: clamp(1.6rem, 3.5vw, 2.15rem), h3: 1.3rem.
  • Body Fonts: System sans-serif stack (system-ui, -apple-system, "Segoe UI", Roboto, Arial, sans-serif) at 1rem (16 px) with 1.65 line height for comfortable reading.

Components

  • Buttons: Pill-shaped buttons (.btn-clay ocean-blue primary, .btn-blue deep-navy secondary, .btn-outline-sand glass outline).
  • Cards: Rounded 20 px white Bento cards (.info-card, .topic-card) with a 4 px top gradient accent bar and lift-on-hover shadow.
  • Navigation Bar: Sticky floating capsule (border-radius: 999px) with liquid-glass blur (backdrop-filter: blur(22px) saturate(180%)).
  • Forms: Rounded 12 px inputs (.form-control) with ice-alabaster background, ocean-blue focus ring and inline .invalid-feedback alerts.

9. Responsive Design Plan

Target Device Breakpoint / Viewport Grid & Layout Behaviour Navigation & Interactive Adjustments Device Screenshot
Desktop ≥ 992 px (Bootstrap lg / xl) 3-column card grids (col-lg-4), 2-column split Hero, Welcome Bento and Registration panels. Full horizontal floating liquid-glass capsule navbar with all 7 links visible; 440 px carousel height.
Tablet 768 px – 991 px (Bootstrap md) 2-column card grids (col-md-6); Hero and Registration panels stack vertically for readability. Capsule navbar collapses into a toggle button (.navbar-toggler) opening a rounded dropdown menu.
Mobile Devices < 768 px (Bootstrap sm / xs) Single-column vertical stack (col-12); mini-Bento grid switches to 1 column (grid-template-columns: 1fr). Buttons expand to width: 100% for easy thumb tapping; carousel height reduces to 360 px with compact glass captions.

AI Tool Purpose Prompt Used Output Generated Modifications Made
ChatGPT Planning & Content Drafting “Outline a 7-page informational website for ICT and Cybersecurity students preparing for internships, including career paths, CV tips and interview questions.” Produced a generic 7-page outline with US-focused salary figures and broad software engineering advice.
